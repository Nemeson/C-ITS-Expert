## 1. Executive Summary & Problem Statement

Cooperative Intelligent Transport Systems (C-ITS) in Europe (ETSI TC-ITS, C-Roads, ISO TS 19091) depend on high-precision intersection geometries (MAPEM) and dynamic signal phases (SPATEM). However, development and auditing are severely impeded by three physical realities:
1. **Disconnected Tooling:** Engineers must jump between raw Wireshark hex dissections, GIS viewers (QGIS/Google Earth), and proprietary traffic controller software (LISA+ / VS-PLUS).
2. **Abstract Numerical Identifiers:** Real field captures transmit raw integer IDs (`signalGroupID = 3`), while traffic engineers and field technicians strictly refer to physical phase designations (`K3: Linksabbieger B170 Nord`, `F5: Fußgängerfurt`).
3. **Geometry Distortion:** Incorrect node sequencing (connecting Node $N$ instead of Node 0 Stoplines) causes 5-fold overlong diagonal chords that distort spatial analysis and GLOSA trajectory forecasts.

This milestone introduces an integrated, pure-Python visualization and infrastructure compiler subsystem into `cits_expert`:
- **3D KML & GeoJSON Exporter:** Pure-Python converter from MAPEM/SPATEM topologies into 3D GIS formats without third-party dependencies.
- **LISA `LV.XML` Supply Compiler:** Automated parser and classifier mapping numeric C-ITS signal groups to human-readable engineer designations (`K1`, `K2`, `F5`, `Ö1`).
- **GLOSA Trajectory Engine:** High-precision Green Light Optimal Speed Advisory calculator computing legal speed corridors $[v_{min}, v_{max}]$.
- **CLI & MCP Tooling:** Exposed via `cits-export` CLI and agent tools `cits_export_kml`, `cits_parse_lisa`, `cits_compute_glosa`.

## 3. Component Specifications

### 3.1 LISA `LV.XML` Supply Compiler (`cits_validator/lisa/`)
* **Input:** XML files generated by LISA+ traffic controller planning suites (`LV.XML`, `VDX`).
* **Attributes Parsed:**
  * `ObjNr`: Integer ID corresponding to C-ITS `signalGroupID`.
  * `Bezeichnung`: Technical designation (e.g. `K1`, `K2`, `F5`, `R17`, `Ö1`).
  * `Kommentar` / `Name`: Full textual description (e.g. "B170 Nord Richtung Dresden").
  * `Ansteuerung`: Signal aspects (`Rot`, `Gelb`, `Gruen`).
* **Classification Logic:**
  * Prefix `F` / `FG`: `pedestrian`
  * Prefix `R` / `RAD`: `bicycle`
  * Prefix `B` / `BUS` / `TRAM` / `STRAB`: `transit`
  * Prefix `K` / `KFZ` / `SG`: `vehicle`
  * Special aspect cases: Gelb+Grün separated turn signals (e.g. `K11`) are classified as `vehicle` despite missing red.
  * Two-aspect fallback (Red + Green without Yellow) defaults to `pedestrian`.

### 3.2 3D KML & GeoJSON Builder (`cits_validator/geo/`)
* **Standards Compliance:** OGC KML 2.2 and RFC 7946 GeoJSON.
* **Stopline Marker Visualization:**
  * Ingress Stoplines (Node 0) rendered with dedicated stopline bars perpendicular to lane azimuth.
  * Egress lanes rendered in distinct color palettes (Ingress: Cyan `#00e5ff`, Egress: Emerald `#00e676`, Crosswalks: Orange `#ff9100`, Connections: Yellow `#ffea00`).
* **3D Coordinate Tuples:** Output coordinates formatted as `(lon, lat, altitude)`.

### 3.3 GLOSA Advisory Engine (`cits_validator/geo/glosa.py`)
* **Input Parameters:**
  * $d$: Remaining distance to Node 0 Stopline in meters.
  * $v_0$: Current vehicle approach speed in km/h.
  * $v_{limit}$: Street speed limit in km/h (e.g. 50 km/h).
  * $v_{min\_comfort}$: Minimum comfortable approach speed in km/h (e.g. 20 km/h).
  * SPAT countdown parameters: `minEndTime`, `maxEndTime`, current signal state (`red`, `yellow`, `green`).
* **Output:**
  * `advisory_speed_min_kmh`, `advisory_speed_max_kmh`.
  * `recommendation`: `"CRUISE"`, `"ACCELERATE_TO_GREEN"`, `"DECELERATE_FOR_GREEN"`, `"PREPARE_TO_STOP"`.
  * `time_to_stopline_seconds`.

## 4. Interfaces & Agent Integration

### CLI: `cits-export`
```bash
cits-export --mapem intersection.json --spat spat.json --lisa supply.xml --format kml --output intersection.kml
```

### MCP Agent Tools
* `cits_parse_lisa(xml_content: str)`: Parses and classifies LISA `LV.XML` into structured JSON catalog.
* `cits_export_kml(lanes_json: dict, lisa_catalog: dict | None)`: Generates valid 3D KML document.
* `cits_compute_glosa(distance_m: float, speed_kmh: float, spat_phase: dict)`: Returns instant GLOSA advisory speed window.
